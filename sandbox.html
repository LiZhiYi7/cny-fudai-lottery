新春福袋抓抓乐 · 像素素材沙盒 640×360 · 1:1

所有画布都是内部 640×360 的 1:1 显示（不缩放），用于逐像素检查美术资源。全部由 src/js/render/ 下的 ESM 模块绘制，无外部图片 / 字体 / 网络资源。

请通过 Electron 窗口或本地静态服务器打开本页（file:// 下浏览器会拦截 ESM）。 滚动到哪个区块，哪个区块的动画才刷新；只显示可视区域以保证流畅。

1. 背景场景 · Background

夜空 / 星星 / 月亮 / 庙檐剪影 / 灯笼串 / 飘雪 / 前景观众。静态层已缓存到离屏画布。

2. 抓娃娃机 · 阶段（6 个）

状态协议：phase / clawX / clawY / clawOpen / grab / pouches / goldId / misses / assist / spotlight / revealNumber。 另含 miss、retry 两态（文字提示 + 未中红点），主流程可直接传 phase 使用。

3. 福袋 / 金福袋 / 爪子特写

福袋：红袋身 + 金边 + 抽绳 + 福字 + 高光；金福袋更大、发光、上下漂浮、环绕星光。 爪子：金属爪 + 钢丝绳 + 滑块，clawOpen 控制开合，grab 时夹住福袋。

4. 标题 / 揭晓卡片 / 玩家令牌

Art.title(ctx,t) + Art.winnerCard({number,prize,levelName,t,accuracy}) + Art.playerToken({number,x,y,scale,won,dim,t})。 令牌 (x,y) 为令牌中心；难度星标默认 (x,y) 为左上角。

5. 面板 / 按钮 / 图标

Art.panel 四种 variant：dark / red / gold / plain；Art.button 支持 hover、disabled、primary、pressed； Art.icon 8 个图标（中心锚点），(scale=2) 时 32×32。

6. 粒子与屏幕效果

FX.update / drawBack / drawFront / getShake；按钮可实时触发烟花、金币雨、彩纸、火花、开奖光环、闪白、震屏。 粒子上限 400。

沙盒仅为美术自检页，不属于正式游戏入口。正式入口是 index.html（Lead 维护）。 像素素材全部使用整数矩形 / 布里森汉姆线段 / 逐行圆绘制，imageSmoothingEnabled = false，无抗锯齿、无外部资源。
