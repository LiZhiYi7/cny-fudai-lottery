# exe 冒烟检查清单

构建产物（便携版）：

```text
dist\新春福袋抓抓乐-1.0.0-portable.exe
```

建议把 exe 复制到一个**空文件夹**（例如 `D:\qa-smoke\`）再检查，避免和开发目录里的 `data/` 混淆。
逐项勾选，全部通过才算本次打包可用。

## 0. 前置准备

- [ ] `npm install` 成功，`npm run build:win` 退出码为 0，`dist\` 下有 exe。
- [ ] 复制 exe 到空文件夹 `D:\qa-smoke\`。
- [ ] 记录测试机：Windows 版本 / 屏幕分辨率 / 是否有杀毒软件。

## 1. 启动与标题

- [ ] 双击 exe 能启动（首次启动解压可能需要数秒，期间不要重复双击）。
- [ ] 窗口标题为「新春福袋抓抓乐」，窗口默认 1280×720 左右，无白屏、无报错弹窗。
- [ ] 首页能正常显示标题、按钮、底部状态文字，且标题下方显示「N 人 / M 关」。
- [ ] 没有额外的开发者工具或菜单栏。

## 2. 数据目录

- [ ] 首次启动后，`D:\qa-smoke\data\` 自动出现，至少包含 `config.json`、`results.json`。
- [ ] 打开 `config.json`，内容是合法 JSON（标题、playerCount、levels、pin 等字段）。
- [ ] 后台管理 →「打开数据目录」能打开同一个 `data\` 文件夹。
- [ ] 若 `D:\qa-smoke\` 不可写（例如只读盘），程序仍可启动，数据落在 `%APPDATA%\新春福袋抓抓乐\data\`（记录实际位置）。

## 3. 离线可用

- [ ] 断网（拔网线 / 关 Wi-Fi）后启动，首页、后台、抽奖、音效、CSV 导出全部正常。
- [ ] 任务管理器无异常网络连接；游戏不需要任何在线资源。

## 4. 拷贝到别的文件夹 / 别的电脑

- [ ] 关闭程序，把整个 `D:\qa-smoke\`（exe + `data\`）复制到 `D:\qa-smoke2\`，启动后抽奖记录与配置都还在。
- [ ] 只复制 exe（不带 `data\`）到新文件夹，启动后能正常使用，配置为默认值（12 人 4 关，密码 8888），并自动生成新的 `data\`。
- [ ] 把 `data\` 从 U 盘还原回另一台电脑后，记录可读、兑奖清单正常。

## 5. 分辨率与窗口

- [ ] 1280×720 窗口：画面居中显示，无裁切、无页面滚动条。
- [ ] 1920×1080 全屏（`F11`）：画面等比放大居中，像素保持锐利，无拉伸变形。
- [ ] `F11` 再按一次可退出全屏。
- [ ] 把窗口拉到最小（960×540）：画面仍居中，无崩溃。
- [ ] 关闭再启动：窗口大小/位置被记住（`data\state.json` 存在且数值合理）。

## 6. 主流程（3 人 2 关，各 1 人，简单 / 普通）

- [ ] 首页 →「后台管理」→ 输入默认密码 `8888` 能进入。
- [ ] 设置人数 3、两关各 1 人，保存后首页底部显示「3 人 / 2 关」。
- [ ] 开始抽奖 → 名单页显示 3 个号码牌与 2 关奖品，无溢出。
- [ ] 按空格/点击「开始抓取」进入第一关，倒计时后可移动爪子并抓取。
- [ ] 抓中后揭晓中奖号码在 1–3 之间，号码与奖品显示正确，音效/特效正常。
- [ ]「继续」进入第二关；再次中奖后，两人号码**不重复**。
- [ ] 终场显示 2 位中奖名单与「本局中奖名单」。
- [ ] 打开「查看兑奖清单」：2 行记录，勾选「已兑付」后状态同步、`results.json` 中 `paid` 变为 `true`。
- [ ] 关闭清单 → 关闭程序 → 重新打开：首页显示上一局记录，兑奖清单勾选状态保留。
- [ ] 导出 CSV：能弹出保存对话框；用 Excel 打开中文不乱码，表头/奖品/号码/兑付状态正确。
- [ ] 打印兑奖单：能打开打印预览，A4 一页内，含签字栏与已兑付勾选。

## 7. 异常与边界

- [ ] 后台把人数改成 3、两关名额合计改成 5（> 3）且不开启重复中奖：保存/开始时被拦截并提示「名额合计…超过玩家总数」。
- [ ] 后台把密码改成 4 位数字，能保存；重启后旧密码失效、新密码可进入。
- [ ] 空奖品名 / 空关卡名 / 超长文本会被拦下并提示。
- [ ] 对局未结束时点窗口关闭按钮：出现「对局还没结束」确认框；取消可继续，确认后正常退出。
- [ ] 对局结束后直接关闭窗口：不再弹确认。
- [ ] 单实例：程序已打开时再次双击 exe，不会启动第二个窗口。
- [ ] 连续开始新一局：上一局记录出现在 `data\archive\` 下（文件名含时间戳与对局 id）。

## 8. 使用调试参数自测（可选）

Electron 主进程支持截图参数，可在无人值守时验证画面能绘制：

```powershell
.\新春福袋抓抓乐-1.0.0-portable.exe --screenshot D:\qa-smoke\shot-home.png --screen home
.\新春福袋抓抓乐-1.0.0-portable.exe --screenshot D:\qa-smoke\shot-sheet.png --screen sheet --test
```

- [ ] 生成 PNG 且不是纯黑/纯白，界面元素完整。
- [ ] 进程截图后自动退出，不留后台进程。

> 注：`--test` 会暴露 `window.__gameTest` 测试钩子；正式现场直接双击 exe，不要带该参数。

## 9. SmartScreen 与安全软件

- [ ] 未签名 exe 首次运行出现 SmartScreen：点「更多信息」→「仍要运行」后能正常启动（属预期）。
- [ ] 杀毒软件未误报隔离；如有告警，记录软件名称与处置方式。
- [ ] exe 属性中「产品名称」「文件版本」显示正常（electron-builder 生成）。
